# Support

## GitHub development issues

Found a bug, a mistake in a guide, or something you’d like to improve? Open an
issue in the project it belongs to. Search existing issues first, then use the
project’s instructions and templates.

Tell us which version you’re using and how to reproduce the problem. Include
relevant environment details, but remove secrets, private URLs, and personal
data from anything you share.

## Product and customer support

- Read the [documentation](https://docs.wpultimatesecurity.com/) for setup and
  troubleshooting guidance.
- Use the [WordPress.org plugin support forum](https://wordpress.org/support/plugin/ultimate-security/)
  for public plugin support questions.
- Email [support@wpultimatesecurity.com](mailto:support@wpultimatesecurity.com)
  for product or customer questions.

Do not post account details, site credentials, or customer data in public forums.
Never include passwords or access tokens in an initial support request.

## Security vulnerabilities

Do not disclose vulnerabilities in public issues or support threads. Follow the
affected repository's security policy, or the
[organization security policy](https://github.com/wpultimatesecurity/.github/blob/dev/SECURITY.md)
when no repository-specific policy exists.
